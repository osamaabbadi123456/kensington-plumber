## Integration rules
1. These are illustrative brand/editorial visuals, not evidence of completed jobs, real properties, engineers, products or attendance.
2. Do not add copy implying 24/7, same-day, response time, local premises, reviews, Gas Safe, pricing or guaranteed availability.
3. Use responsive image rendering with explicit dimensions/aspect ratio and no destructive mobile crop.
4. Keep page text complete without relying on the visual for safety instructions.
5. Use meaningful alt text only when the image adds information; otherwise use empty alt for decorative use.
6. Optimise large PNGs to AVIF/WebP for delivery while preserving the source files. Keep PNG originals in the repo asset-source folder if desired.
7. Do not place all visuals above the fold. Only the page's highest-value visual should load eagerly if it is actually the LCP; otherwise lazy-load below-fold images.
8. Verify on 390px, 768px and desktop after integration.
